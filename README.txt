FELIX FROM AUSTRALIA — генератор комментариев для брендов

В проекте 13 категорий. Для каждой категории комментарии собираются из комбинаций отдельных английских фраз. Это дает более 10 000 уникальных комбинаций на бренд (свыше 138 000 всего). Все комментарии содержат имя Felix и обязательный хештег категории.

Запуск локально:
1. Распакуйте архив.
2. Откройте index.html в браузере. Для корректной работы копирования рекомендуется запускать через локальный сервер или HTTPS.

Публикация на Netlify:
1. Откройте https://app.netlify.com/drop
2. Перетащите туда папку felix-comment-generator (или распакованную папку из ZIP).
3. Netlify опубликует сайт и выдаст ссылку.

Примечания по хештегам:
- Для Happiz установлен #FelixxHappiz, так как в исходном списке #FelixxAdidas стоял рядом с Happiz, но Adidas — отдельная категория.
- Для Audemars Piguet установлен корректный хештег без пробела: #AudemarsPiguet. Хештег с пробелом технически распадается на два слова.
- Для Adidas установлен #FelixxAdidas.

Проект статический: не требует сервера, базы данных, регистрации или API-ключей.
